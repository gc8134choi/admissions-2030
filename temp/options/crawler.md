# 감시 방식 대안 (선택: A)
- **A (선택)**: GitHub Actions가 매일 감시 목록의 URL을 해시 비교해 변경 목록을 PR 또는 이슈로 올린다. 매주 수요일 감시 세션(에이전트)이 변경된 출처만 읽어 policy-draft를 갱신하고 PR로 올린다. 장점: 싸고 재현 가능, 에이전트는 필요할 때만. 단점: 해시는 사소한 변화에도 반응하므로 정규화가 필요.
- B: 에이전트 세션이 매일 모든 출처를 읽는다. 정확하지만 비용이 크고 매번 맥락이 없다.
- C: 외부 모니터링 서비스(이메일 알림). 구현은 쉽지만 저장소 데이터와 연결되지 않고 계정 의존.
