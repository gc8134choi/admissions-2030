## 변경률

- 검토한 화면 문구(따옴표 문자열 약 470개 + 메뉴 이름·설명 22쌍): 변경 10건(13곳, 중복 위치 포함) → 문구 단위 약 2.7%. 이름·사실·수치·날짜·학교명·제도명은 한 글자도 바꾸지 않았다.

## 건드리지 않은 이유

- 메뉴 항목 이름: 이름 시험(92~95%)에서 검증된 이름이라 유지. 설명 줄은 이미 짧은 명사 나열이고 check-menu-captions 핵심어가 걸려 있어 유지.
- 홈 블록 제목(곧 있을 일·고등학교 일정·소개)·버튼(사진 넣기·전체 일정): 짧고 평이해서 유지.
- 검색 안내(없음·gap·none, where-*): 대부분 "~에서 확인해요" 한 가지 틀로 일관되고 gold·check-search-notices가 기대 문구를 본다. "해당 학교·교육지원청" 같은 말은 뜻이 분명해 유지.
- 자료실 갱신 현황·원본 파일 화면의 "입니다" 문장: 한계·대조 완료를 밝히는 문구라 표현을 건드리지 않았다. 해요체와 말투가 다르다는 점만 기록(통일 여부는 PM 판단).
- "해당 과목 수"(표 행 이름)·"살펴볼 점"(고교 유형 단점 항목): 뜻이 달라질 수 있어 유지.
