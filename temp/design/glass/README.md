## 바뀐 점(`portal/glass.css`, 스크랩북 층 위에 얹음. 롤백 = `index.html`의 glass.css 링크 제거)
- **배경**: 외부 사진 없이 CSS로 그린 따뜻한 보케(radial-gradient 4개, 고정 레이어 1개). 밝은 모드는 같은 구도의 밝은 변형.
- **패널**: 종이 조각(기울임·테이프·찢김·질감)을 없애고 `rgba` 반투명 + 1px 테두리 + 부드러운 그림자. 모서리 반경은 10/14/20px로 섞음. 패널마다 `backdrop-filter`는 걸지 않음(하단 탭 1개만).
- **색**: 다크 포인트는 `#FF7F32`(주황 계열, 다크 표면 위 대비 5.2 이상으로 실측). 밝은 모드는 기존 `#C4310D`. 필수/내가 고르는/보도·추정 색은 고정(다크용 밝은 변형만).
- **글자**: 손글씨·명조를 쓰지 않고 본문 글꼴 하나로 굵기 위계. 본문 15/16, 보조 13 하한 유지.
- **크기**: 패널 안쪽 여백 8~12px, 제목 16px, 큰 숫자 축소.
- **유지**: 메뉴 5개+보관함, 정보 구조, 주소·저장 데이터, 접근성(터치 44/48, 대비 AA, reduced-transparency/contrast).

## 성능 회복 후보 (쉬운 순)
1. Pretendard 동적 서브셋 CSS는 이미 print→all 지연 로드. 글래스에서 쓰지 않는 Gaegu/Gowun 폰트 preload 2건 제거(index.html) — 홈 초기 요청 2건 감소. 되돌리기 쉬움.
2. 홈에서 쓰지 않는 JS(planner.js, middle.js, map.js, hs-compare.js)가 sw 사전 캐시에만 있고 홈은 동적 import인지 확인 후 분할 유지.
3. glass.css는 dense.css 위에 덮는 구조라 CSS 총량이 큼(약 +10KB) — 안정되면 scrap/dense와 병합해 중복 규칙 삭제.
4. 배경 bokeh는 고정 레이어 1개(래스터 없음). 다중 radial-gradient 4개를 2개로 줄이면 페인트 비용 감소.
