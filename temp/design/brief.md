# 예나·예은 대입 포털 디자인 브리프 (temp, 2026-10-25)

작성: 디자인 리서치 세션. 목업: `temp/design/A|B|C/index.html`, 캡처: `temp/design/screens/`. 기존 `portal/` 코드는 수정하지 않았고, 숫자·일정은 `portal/data/*.json` 값만 썼다.

## 0. 핵심 요약 (1,800자 이내)

**진단.** 현재 화면의 AI 티는 하나의 원인이 아니라 "모든 정보를 같은 모양의 둥근 상자에 같은 무게로 담는 것"에서 나온다. 홈의 남색 그라디언트 히어로, 왼쪽 색 막대가 있는 숫자 타일 5개(192·174·18·16회·2/3)가 한 줄에 균일하게 놓인 구조, 타일마다 다른 파스텔 틴트, 모서리 아이콘, 모든 곳의 알약 배지가 대표적이다.

**처방.** 상자를 없애고 ① 큰 글자가 주인공이 되게 하고 ② 헤어라인과 여백으로 구분하고 ③ 색은 사람(프로필)당 하나만 쓰고 ④ 상태 표시는 알약 대신 점+글자로 바꾼다. 사진·일러스트는 직접 그린 것만 쓴다.

**새 요구 반영.** 이 포털은 예나(2030학년도 대입)와 예은(2033학년도 대입)이 함께 쓴다. 제목은 "예나·예은 대입 포털". 중립 베이스(따뜻한 종이색+먹색) 위에 프로필별 포인트색 2개(`--accent-a` 버밀리언 #C4310D, `--accent-b` 아이리스 #4B3FD6)를 얹고, 전환하면 히어로 숫자·활성 탭·링크·체크박스 색만 바뀐다. 상태색(확정/보도/추정)과 지정(남색)/선택(초록)은 프로필과 무관하게 고정한다. 두 색은 명도(OKLCH L 0.50~0.56)와 채도(C 0.18~0.20)를 맞추고 색상만 115도 떨어뜨렸다. 배경에 색을 깔지 않으므로 파스텔 틴트가 생기지 않는다. 예은은 학교가 아직 없어 "학교를 고르면 여기에 모입니다" 빈 상태가 홈의 3곳(일정·학교·할 일)에 들어간다.

**3안.** A 에디토리얼(흑백+강조색 1개, 헤어라인, 비대칭 그리드), B 대화형(한 화면 한 메시지, 큰 숫자, 바텀시트), C 스크랩북(종이 질감, 손글씨, 스티커). **추천은 A.** 근거: 3년간 매일 쓰는 도구라 질리지 않는 정적 구조가 중요하고, 정보 밀도(출처·상태·날짜)를 가장 잘 견디며, 구현이 CSS 토큰과 마크업 수정으로 끝나 프레임워크·빌드 없는 현재 구조와 맞는다. B의 "한 줄 한 문장" 카피와 바텀시트 전환, C의 빈 상태 일러스트는 A에 일부 차용할 가치가 있다.

**메뉴.** 하단 탭 5개: 오늘 / 일정 / 학교 / 알아두기 / 보관함. "제도 변경 로그"는 "바뀐 소식"으로 바꿔 알아두기 안으로, 준비 중 메뉴(플래너 3종)는 숨기고 학교 탭의 "곧 열려요" 한 줄로 줄인다. 외부 링크는 보관함의 "바로가기"와 각 일정 행의 출처 링크 두 곳에만 둔다. 프로필 전환은 모바일 하단(탭 바로 위 44px 줄) 또는 헤더 시트, 스와이프 3가지를 지원한다.

**주의.** 레퍼런스는 검색 결과 요약에 근거했다(원문 페이지 직접 열람은 네트워크 제한으로 실패). 앱 화면 자체는 개발 전 사람이 직접 열어 확인해야 한다(10절).

## 1. AI 티 체크리스트

현재 화면(`screens/now-*.png`)에서 확인한 패턴.

| # | 패턴 | 현재 화면 위치 | 왜 AI 같은가 | 대안 (구체값) |
|---|---|---|---|---|
| 1 | 균일한 둥근 사각형 카드 격자 | 홈 "이어지는 일정", "관심 학교" 큰 흰 상자, 학점제 숫자 타일 5개 | 모든 정보가 같은 반경(16px)·같은 그림자·같은 흰 상자에 담겨 위계가 없다 | 상자 제거. 구분은 `border-top:1px solid var(--rule)`(섹션)과 `var(--hair)`(행). 카드가 꼭 필요하면 C안처럼 각도·종이 조각처럼 서로 다르게 |
| 2 | 왼쪽 색 막대 | 학점제 숫자 타일 `border-left:4px` 5색 | 템플릿 대시보드의 상징 | 삭제. 숫자 자체를 크게(`font-size:clamp(52px,15vw,84px)`) |
| 3 | 파스텔 틴트 배경 | 숫자 타일 5색 연한 배경, 학점제 히어로 하늘→살구 그라디언트 | 색마다 "연한 10%" 틴트를 깔면 생성형 UI의 전형 | 배경은 중립 2색(종이 `#FAF9F6`, 띠 `#F1EFEA`)만. 포인트색은 글자·선·체크에만 |

| 6 | 그라디언트 배너 | 홈 남색→청색 히어로, 상단 헤더 | 가장 흔한 AI 첫 화면 | 단색 배경 + 큰 숫자. 헤더는 `border-bottom:1px solid` 한 줄 |
| 7 | 이모지·제네릭 아이콘 | 메뉴 아이콘 세트, ★ 토글 | 라이브러리 아이콘 그대로 | 하단 탭은 글자만(A) 또는 직접 그린 2px 선 아이콘(B). 탭에 과한 아이콘 금지 |
| 8 | 동일 간격·동일 반경 | `--r:16px`, `--gap:32px`, `--pad:24px`가 전역 | 리듬이 없다 | 4/8/16/40/72 불규칙 스케일. 섹션 간 40~72, 행 간 16~18, 안쪽 8~14 |
| 9 | 3~6개 균일 타일 행 | 숫자 5개 한 줄, 학교 4개 한 줄 | 정보 위계 부재 | 가장 중요한 숫자(192)를 2~4배 크게, 나머지는 비대칭 격자(A) 또는 문장과 짝(B) |
| 10 | 제네릭 일러스트 | 학점제 히어로 집+책+졸업모 | 스톡 느낌 | 쓰려면 한 장만, 선 하나로 직접 그린 것(C `.slot svg`) |
| 11 | 설명문 같은 문구 | "지금 할 일, 관심 학교, 최근 변경을 한눈에" | 기능 설명 | 3절·6절의 짧은 말. 주어 없이 사용자에게 건네는 문장 |
| 12 | 라벨-값 쌍을 모두 `.card`로 | 편제표 요약(192/120/54) | 요약 지표가 상자 3개 | 줄 하나: `120 + 54` + 2px 막대(지정 남색, 선택 초록) |

**대안 원칙 5개.** 1) 숫자·문장이 주인공(타이포 위계 3단계 이상) 2) 헤어라인과 여백(구분은 선, 묶음은 간격) 3) 비대칭(좌 7 : 우 5 열) 4) 사람당 강조색 1개 5) 직접 그린 것만(로고는 학교 로고만, 그림은 인라인 SVG).

### 3-2. 추천: A안 (작업 진행안)

1. **정보형 사이트다.** 출처 URL·상태(확정/보도/추정)·날짜를 항상 붙여야 하는데, 헤어라인 행 구조가 이를 가장 깔끔하게 담는다(목업의 `.row`, `.st`).
2. **3년을 쓴다.** 질리지 않는 중립 베이스에 사람별 포인트색만 바꿔도 충분히 개인화된다. C의 질감은 6개월 후 피로해질 위험이 크다.
3. **AI 티 제거 효과가 가장 크다.** 상자·색 막대·틴트·알약을 모두 없애도 정보가 읽힌다(스크린샷 `A-390.png` 참고).
4. **구현 비용이 가장 낮다.** `portal/style.css`의 `:root` 토큰 교체와 마크업 단순화가 중심이다.
5. B와 C에서 가져올 것: B의 한 문장 메시지와 바텀시트 프로필 전환(A의 상단 띠를 대체 가능), C의 빈 상태 선 일러스트와 "손 체크" 느낌(체크박스 사각형 + 포인트색 채움으로 단순화).

### 3-3. 컬러 토큰 (A안 기준, 개발 세션이 그대로 복사)

```css
:root{
  --paper:#FAF9F6; --ink:#111110; --mute:#6A6963;       /* 보조글 대비 5.2:1 */
  --hair:rgba(17,17,16,.16); --rule:#111110;
  --accent-a:#C4310D;   /* 예나 · OKLCH ≈ L.52 C.19 h35  · 종이 위 대비 5.3:1 */
  --accent-b:#4B3FD6;   /* 예은 · OKLCH ≈ L.50 C.20 h280 · 종이 위 대비 6.7:1 */
  --accent:var(--accent-a);
  --st-est:#9A5B00;     /* 추정 · 5.2:1 */
  --req:#1B3A6B; --ele:#0B7F63;   /* 지정/선택 고정 */
}
[data-profile=b]{--accent:var(--accent-b)}
@media (prefers-color-scheme:dark){:root:not([data-theme=light]){
  --paper:#111110;--ink:#F4F2EC;--mute:#9C9A92;--hair:rgba(244,242,236,.18);--rule:#F4F2EC;
  --accent-a:#FF6A45;--accent-b:#8F85FF;--st-est:#F0B04A;--req:#6EA0F0;--ele:#34D3A8}}
```

두 색 규칙(프로필 확장 시에도 지킬 것):
1. 명도 L 0.50~0.56, 채도 C 0.18~0.20(다크는 L 0.70~0.74, C 0.17). 둘이 같은 "무게"여야 한쪽이 튀지 않는다.
2. 색상각은 서로 100도 이상 떨어뜨린다(예나 35, 예은 280). 상태색(앰버 약 70도)·지정(남색 약 260도)·선택(초록 약 170도)과 겹치지 않게 한다. 예은 포인트(280도)는 지정 남색(260도)과 가깝지만, 남색은 어둡고 채도가 낮아(L .33) 구분된다. 한 화면에 두 색을 같이 쓰는 곳은 두 사람 D-day 띠뿐이다.
3. **배경 면적에 쓰지 않는다**(연한 틴트 금지). 쓰는 곳: 18px 이상 700 글자, 2~3px 선, 체크 채움, 활성 탭 표시, B안의 버튼 면(흰 글자 대비 5.3/7.0:1)만.
4. 작은 글자(12~14px)에는 포인트색을 쓰지 않거나 `--ink`로 쓴다(예나색은 15.5px 이하 글자에서 4.5:1 경계).
5. 확정=먹 채움 점, 보도=반 채움 점, 추정=`--st-est` 빈 점. 프로필과 무관.

### 3-4. 레이아웃·간격 값

- 모바일 여백 20px, 최대폭 1120px, 데스크톱 좌우 40px.

1. 하단 탭·사이드 메뉴에 "준비 중" 항목을 두지 않는다(현재 사이드 메뉴에는 "준비 중" 표시가 8곳 붙어 미완성처럼 보인다).
2. 준비 중 기능은 해당 탭 안의 맨 아래 한 줄 "곧 열려요: 내 계획표 · 학교별 시뮬레이션"(클릭 불가, 텍스트).
3. 열리는 날 기존 탭에 서브 탭으로 추가(메뉴 구조는 바뀌지 않음).

### 5-4. 학년별 시간 축

- 전역 상단에 스티키 가로 탭 1줄: **중3 겨울 · 고1 · 고2 · 고3 · 수능**(예은은 같은 줄에 초6 겨울·중1·중2·중3·고1~ 로 확장되도록 `profiles.json`의 `timeline` 배열로 정의).
- 현재 학년이 기본 선택, 지난 학년은 `--mute`. 일정·알아두기·학교에서 같은 축을 공유한다.
- 학년이 바뀌면 홈 상단 한 줄 문구만 바뀌고(예: "고1이 됐어요"), 메뉴는 그대로(3년간 구조 유지).

### 5-5. 외부 링크 허브

- 위치: **보관함 > 바로가기** 한 곳(어디가, 대학알리미, 고교학점제 종합지원포털, 교육청 고입 포털, 평가원 수능, 대교협). 홈에는 두지 않는다.
- 각 일정 행·숫자 아래에 출처 링크 한 개(`.src`)만 둔다. 외부 링크는 `rel="noopener"`와 "↗" 표시.
- 상태별 출처 구분: 공식(교육부·평가원·대교협·교육청) = 먹 글자, 매체 = `--mute` 글자 + "보도".

### 5-6. 데스크톱 내비

- 좌측 사이드 트리를 없애고 상단 한 줄 글자 메뉴(5개) + 우측에 프로필 전환(A `.sw`). 하위 항목은 페이지 안 탭으로 올린다.

## 6. 메시지·마이크로카피 가이드

### 6-1. 톤 원칙

1. 해요체(존대)를 기본으로 하되 문장은 짧게. 토스의 "잡초 뽑기"처럼 의미 없는 말을 걷는다.
2. 한 화면에 한 가지 일(One Thing per Screen)을 말한다. 헤드라인은 사실, 보조 줄은 해야 할 일.
3. 중3 본인과 학부모 둘 다 읽는다. 은어·이모지·감탄사 금지, 의인화 금지("저는 ~예요" 안 씀).
4. 확정되지 않은 것은 확정처럼 쓰지 않는다. 불확실하면 "~로 예상돼요 / 아직 확정은 아니에요".
5. 오류·빈 상태는 원인 + 다음 행동 한 줄. 사과는 한 번만.
6. 압박 금지: "~까지 안 하면" 같은 문구 대신 "~까지 볼 수 있어요".
