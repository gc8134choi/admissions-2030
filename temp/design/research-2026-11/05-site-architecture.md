# 참고 사이트 사이트 아키텍처 조사 (2026-11-01)

한계: 이 세션은 대상 사이트에 직접 접속할 수 없어(WebFetch DNS 차단) 검색 결과 요약과 제3자 자료만 썼다. 메뉴 라벨·URL 세부는 대부분 **미검증**이며, 실제 사이트에서 확인이 필요하다.

## 1. 사이트별 조사

### 대학어디가 (adiga.kr)
- URL: https://www.adiga.kr (모바일 m.adiga.kr). 근거: https://www.dhnews.co.kr/news/view/179515856761784
- 최상위: 진로정보(직업·심리검사), 대학/학과/전형(대학·학과·전형 정보), 성적분석(학생부·수능), 대입정보센터(자료실·대학별 입시정보), 대입상담(온라인·전화 1600-1615). 이용 순서를 "진로 탐색 → 대입 검색 → 학습 진단 → 상담"으로 안내한다.
- 선택: 엔티티(대학·학과·전형)와 과업(성적분석)을 병렬로 두고, 사람(상담교사)을 최종 출구로 둔다.
- 시사점: 순서 안내(단계별 시작 가이드)가 메뉴가 아니라 문구로 존재한다. 우리도 "처음이면 여기부터"를 오늘 화면에 둘 수 있다. 세부 URL·상세 템플릿은 미검증.

### 학교알리미 (schoolinfo.go.kr)
- URL: https://www.schoolinfo.go.kr/Main.do 근거: 검색 결과 (https://www.yugacrew.com/crewletter/schoolinfo-site-search-guide)
- 최상위: 전국학교정보(학교별·지역별·항목별 공시), 학구도 서비스(전국학교현황, 신설/폐교, 즐겨찾는 학교 비교), 공시항목소개, 정보공개 법규, 알리미 소식, 오류신고 센터.
- 선택: 학교 단위 + 항목 단위 두 축 조회. 즐겨찾기 학교를 같은 학교급끼리 최대 10개 비교(학사/학생, 재정/시설, 보건/복지로 항목 묶음). 공시항목소개·오류신고로 신뢰 장치를 별도 메뉴로 둔다.
- 시사점: "즐겨찾기 → 비교" 흐름과 항목 묶음, 오류신고 접점. 우리 ★관심 학교 + 비교 표와 구조가 같다. URL은 .do 파라미터형이라 공유성은 낮다(우리가 우위 가능).

### 진학사·입시 포털, 에듀넷, 교육청 포털
- 미검증. 이번 조사에서 접속·검색으로 구조를 확인하지 못했다. 일반적으로 상업 포털은 합격예측 같은 도구를 전면에 두고 가이드·뉴스를 하위로 둔다고 알려져 있으나 근거 미확보.

### College Board BigFuture
- URL: https://bigfuture.collegeboard.org 근거: https://bigfuture.collegeboard.org/plan-for-college/own-your-future/what-is-big-future 및 제휴 자료 요약.
- 최상위(자료상): Explore Careers / Plan for College / Pay for College 3개. 대학 찾기는 Plan for College 아래. 개인 대시보드가 핵심 행동(key actions)으로 단계를 안내한다. 최신 메뉴 라벨은 미검증.
- 선택: 과업·단계 중심(계획·비용·진로). 대학 프로필 3,000여 개를 표준 템플릿(전공·학비·요건·주요 일정·캠퍼스)으로 제공.
- 시사점: 3개 큰 과업으로 묶는 단순함, 프로필 표준 섹션 순서, 비용을 별도 축으로.

### UCAS
- URL: https://www.ucas.com 근거: https://dfcdn.ucas.com/latest/pages/dashboard/dashboard.html 및 학교 안내 자료.
- 구조(자료상): Hub에서 탐색 → 단축 목록(하트) → 지원 → 결과 추적의 일직선 흐름. 마감일은 과정 상세의 "How to apply" 안에 있고, 학부모 안내(Advice for parents)가 별도 존재. 상단 메뉴 라벨은 미검증.
- 시사점: 일정이 엔티티 상세 안에 박혀 있어 "이 학교의 마감"이 한곳에서 보인다. 하트 한 번으로 목록에 담기.

### Niche
- URL: https://www.niche.com 근거: https://www.edsurge.com/news/2014-11-03-finding-your-niche-student-and-parents-review-and-give-report-cards-to-k-12-schools
- 구조(자료상): K-12와 대학 모두 프로필 + 영역별 등급(report card) + 후기. 탐색 도구는 퀴즈와 Compare Schools. 목록 저장은 계정 필요(제3자 요약). 메뉴 구조·URL은 미검증.
- 시사점: 점수 한 줄 대신 영역별 요약표, 비교 진입점을 프로필 안에 둠. 후기(사용자 생성)는 우리에게 해당 없음.

### Naviance / Common App / Unifrog
- 근거: https://www.commonapp.org/counselors-and-recommenders/recommender-system, https://www.prweb.com/releases/Common_App_Expands_Integration_Partnerships/prweb17898542.htm
- Common App: "My Colleges" 목록이 허브이고 대학별 요건·추가 서류가 목록 항목 아래 붙는다. Naviance: 대학 조회·비교, 방문 일정, 지원 상태 추적, "Colleges I'm Applying To" 목록. Unifrog: 퀴즈, 대학 검색, 지원서 작성 공간. 모두 "내 목록"이 중심이고 교사/상담 연동이 있다(학교 계약 기반). 라벨·URL 미검증.
- 시사점: 내 목록 하나가 일정·요건·상태의 집계 단위가 된다.

## 2. 공통 패턴 요약
| 항목 | 관찰 | 우리 |
|---|---|---|
| 탐색 모델 | 단계/과업(BigFuture, UCAS) + 엔티티(학교알리미, 어디가) | 단계 탭(좋음) |
| 엔티티 상세 | 고정 섹션 순서의 프로필 | 학교 상세 템플릿 없음(요약+비교 화면) |
| 저장·비교 | 즐겨찾기 → 최대 10개 비교 | ★ 있음, 비교는 필터 화면 |
| 신뢰 | 공시항목소개, 오류신고, 출처 | 상태 표시와 자료실 있으나 화면 곳곳에 분산 |
| 재방문 | 대시보드, 상태 추적 | 오늘 탭, 바뀐 소식, ics |

## 3. 우리 메뉴 트리 격차
현재: 오늘 / 중학교(배정, 지도, 생활) / 고등학교(비교, 지도, 학점제, 계획표, 로드맵) / 대입(규칙, 대학 요건, 입시 일정 + soon) / 일정 + 보관함. 이미 단계 중심이며 메뉴 수도 적다. 격차는 메뉴가 아니라 화면 내부 구조에 있다.
- 일정이 두 곳: 일정 탭, 고등학교 안 로드맵(`schedule?t=road`), 대입 안 입시 일정(`m: () => false`로 활성 표시 안 됨).
- 학교·대학 단위 상세 페이지가 없어 공유·재방문 단위가 약하다.
- 소프트 항목(soon)이 3곳에 문구로 있어 탐색 비용.

## 4. 개선 제안 10개
| # | 제안 | 우선 | 난이도 |
|---|---|---|---|
| 1 | 학교 상세 템플릿(`#school/<id>`): 고정 섹션 순서(개요·편제표·전형·일정·출처), 한 URL에 모음 | 높음 | 중 |
| 2 | 모든 화면 상태를 URL에 반영(필터·비교 대상·탭), 복사 가능한 링크 | 높음 | 중 |
| 3 | 빵부스러기(탭 > 항목 > 학교) 한 줄, 현재 locate() 재사용 | 높음 | 하 |
| 4 | 관련 항목 연결: 상세 하단 "같이 볼 것"(학교→일정→요건→출처) | 중 | 하 |
| 5 | "내 목록"(★ 학교·대학·일정 통합), 로컬 저장, 오늘 화면에 집계 | 높음 | 중 |
| 6 | 단계별 시작 가이드: 오늘 상단 "지금 시기 3가지"(어디가식 순서 안내) | 높음 | 하 |
| 7 | 허브-스포크: 탭 첫 화면을 허브(요약+스포크 링크)로, 하위 목록은 허브에서만 | 중 | 중 |
| 8 | 일정 단일화: 로드맵·입시 일정을 일정 탭의 필터로 흡수, 중복 진입점은 REDIRECT | 중 | 하 |
| 9 | 신뢰 표시 위치 표준화: 모든 상세에 출처·상태·기준일 한 줄을 같은 자리에, 오류 제보 링크(학교알리미식) | 중 | 하 |
| 10 | 재방문 장치: 바뀐 소식을 오늘에 "내 목록 관련 변경만" 노출, 마지막 방문 이후 표시 | 중 | 중 |

## 5. 개선 후 사이트맵 초안 (메뉴 항목 증가 없음)
```
오늘                    시작 가이드(지금 3가지) · 내 목록 요약 · 다가오는 일정 · 내 목록 관련 변경
중학교                  허브: 배정 / 지도 / 생활
  └ #school/<id>        학교 상세(공통 템플릿)
고등학교                허브: 학교 비교(필터) / 지도 / 학점제 / 계획표 / 로드맵
  └ #school/<id>        학교 상세(공통 템플릿)
대입                    허브: 수능·내신 규칙 / 대학 요건
  └ #univ/<id>          대학 요건 상세(공통 템플릿)
일정                    전체 · 필터(로드맵·입시·내 목록) — 로드맵·입시 일정 흡수
보관함(헤더)            내 목록 · 바뀐 소식 · 바로가기 · 출처 · 업데이트 기록 · 원본 파일
```
공통 규칙: 모든 상세는 빵부스러기 + 출처 줄 + 같이 볼 것 + ★ 담기를 같은 자리에 둔다.

## 6. 미검증 요약
진학사·에듀넷·교육청 포털 구조, 해외 사이트 최신 메뉴 라벨, 각 사이트의 URL 체계, 알림 기능 세부. 직접 접속이 가능한 환경에서 재확인한다.
