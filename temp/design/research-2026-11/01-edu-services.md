# 교육·진학 정보 서비스 UX 패턴 조사 (2026-11-01)

한계: WebSearch 요약만 사용했고 각 사이트 화면을 직접 열어 보지 못했다. 국내 일부(학교알리미, 진학사, 에듀넷·교육청 포털)와 Niche·Naviance 화면은 검색 결과에서 UX 근거를 얻지 못해 일반 지식 수준으로만 적고 "미확인"으로 표기한다.

## 1. 국내 사례

### 대입정보포털 어디가 (adiga.kr)
- 근거: https://www.dhnews.co.kr/news/view/1065581092329592 , https://www.hankyung.com/article/2026062822801
- 패턴: 커리어넷(진로)·대학알리미(대학정보)·입학정보를 한 포털로 통합. 권장 동선이 "진로 탐색 → 대입정보 검색 → 학습진단 → 상담" 순서. 모집인원·전형요소·반영비율·지원자격 비교 검색. 성적 등록 후 대학별 전형 기준으로 진단(회원 전용). 최근 대화형 검색·AI 챗봇(멀티턴)을 도입.
- 적용: 단계형 동선(지금 할 일 → 다음 단계)을 홈에 둔다. 비교 항목을 모집인원·전형요소처럼 고정 행으로 통일.
- 피할 점: 로그인 뒤에 핵심 정보를 두는 구조, 점수 나열식 서열화 느낌. 우리는 로그인이 없으므로 기기 저장(localStorage)으로 대체.

### 학교알리미·진학사·입시 커뮤니티·에듀넷/교육청 포털
- 검색에서 UX 근거 미확인. 일반적으로 공시 항목의 표 나열, 학교별 상세 페이지, 커뮤니티의 최신글 위주 노출로 알려져 있으나 이 조사에서는 검증하지 못했다.
- 적용(가설): 학교 단위 상세 + 공시 기준일 표기. 피할 점: 커뮤니티식 비공식 정보와 공식 정보의 혼재(우리는 공식/매체 구분 유지).

## 2. 해외 사례

### College Board BigFuture
- 근거: https://cbsearch.collegeboard.org/how-search-works/features , https://diycollegerankings.com/college-search-websites-big-future-by-the-college-board/3337/ (제3자 리뷰)
- 패턴: 필터 묶음(성적·선발률 / 학교 유형 / 위치 / 캠퍼스·주거 / 전공), 나란히 비교, 관심 목록 저장, 시험 점수 연동으로 "범위 내 학교" 표시.
- 적용: 필터를 5~6개 묶음으로 그룹화해 접는다. 목록 저장과 비교 담기.
- 피할 점: 필터가 많아 처음부터 모두 펼치는 화면.

### UCAS / Common App / Unifrog / Naviance
- 근거: https://www.ucas.com/ucas-tracker (대학 제공자용 대시보드), https://unifrog.org/blog/unifrogs-integration-with-the-common-app-and-parchment-what-is-it , https://www.revisiondojo.com/blog/stay-organized-across-multiple-application-systems
- 패턴: UCAS는 단일 마감일(2027.1.13 18:00 UK)을 크게 표시. Common App은 학교마다 마감이 달라 "내 지원 목록" 기준으로 마감 관리. Naviance는 "지원 중인 대학" 목록과 서류 요청 체크. Unifrog는 진로·진학 도구를 한 계정에 묶고 상담교사가 진행 상황을 봄. 외부 가이드는 "플랫폼이 아니라 대학·과정 단위로 한 줄씩" 관리하는 추적표를 권한다.
- 적용: 일정을 "내가 고른 대상" 기준으로 모으는 개인 추적표. 마감은 D-day와 절대 시각을 함께.
- 피할 점: 상담교사·계정 기반 기능(이름·프로필 금지 제약과 충돌), 학교별 마감이 흩어진 구조.

### Niche
- 검색에서 근거 미확인. 일반적으로 등급·후기 중심으로 알려져 있으나 우리 제약(출처 중심, 후기 배제)과 맞지 않아 참고만 한다.

## 4. 디자인 제약 점검
- 균일 카드 격자 대신 표·목록·섹션 위계로 밀도를 높이고, 강조는 포인트색(#C4310D) 하나만 쓴다.
- 이름·프로필 구분 없이 학년 토글과 기기 저장만으로 맞춤화한다.
- AI 챗봇(어디가 사례)은 환각 위험과 출처 표기 부담이 커서 보류, 검색·필터가 먼저다.
