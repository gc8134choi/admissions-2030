# 02. 개인·가족용 대시보드 디자인 언어 조사 (2026-11-01)

## 1. 사례 (검색 확인은 출처 표기, 나머지는 일반 지식·미검증)
- **Things 3**: 넓은 여백, 시스템 산세리프, 포인트색 1개, 선·박스 최소 ([리뷰, 2차 자료](https://medium.com/@jordanborth/an-ode-to-cultured-code-and-things-3-292e20112624)). 가져올 점: 여백과 크기로 위계. 피할 점: 정보가 많은 우리 화면에 과한 여백.
- **Linear**: 2026.3 개편, "받지 않은 주의를 다투지 않는다", 사이드바를 흐리게, 구분선 축소 ([블로그](https://linear.app/blog/behind-the-latest-design-refresh)). 가져올 점: 메뉴는 낮추고 본문 대비 집중. 피할 점: 개발자 도구식 고밀도 단색.
- **Notion**: 흰 바탕, 글 중심 블록. 가져올 점: 제목 계층. 피할 점: 시각 개성 부족.
- **Apple Health·Screen Time**: 큰 숫자 + 작은 라벨, 요약에서 상세로. 가져올 점: D-day를 큰 숫자 하나로. 피할 점: 같은 크기 카드 반복.
- **Google Calendar·Fantastical**: 시간 축이 위계, 월·주·목록 전환. 가져올 점: 오늘 강조. 피할 점: 색 과다.
- **Toss·카카오뱅크**: 한 화면 한 메시지, 큰 한글 제목, 결론 먼저(Toss는 디자인 컨퍼런스 [Simplicity](https://www.asiae.co.kr/en/article/2021081909291228779) 운영, 세부 원칙은 확인 못 함). 피할 점: 비교표를 쪼개기.
- **네이버 홈**: 고밀도 모듈 스택, 한국 이용자에게 익숙. 피할 점: 광고식 혼잡.
- **Arc·Are.na**: 수집·스크랩 은유, Are.na는 평평한 흑백 블록. 우리 스크랩북과 맞음. 피할 점: Arc식 그라디언트.
- **Bento**: 셀 크기로 중요도 표현. 단점은 과밀, 유행 피로, 획일화 ([freeCodeCamp](https://www.freecodecamp.org/news/bento-grids-in-web-design/), [SaaSFrame](https://www.saasframe.io/blog/the-bento-layout-trend)). 피할 점: 동일 둥근 사각 반복.
- **에디토리얼·신문형**: 헤드라인, 단, 가는 괘선, 포인트 1색. 가져올 점: 카드 없이 괘선으로 구획. 피할 점: 긴 세리프 본문.
- **Calm technology**: 주의 요구 최소화, 필요할 때만 알림 ([O'Reilly](https://oreilly.com/content/principles-calm-technology-we-are-not-bad-at-technology-technology-is-bad-at-us)). 피할 점: 중요 일정까지 숨기기.

공통 결론: 포인트색 1개, 크기·여백·괘선으로 위계, 핵심 숫자 먼저, 크롬은 낮추고 본문 대비를 높임. "AI 느낌"은 균일 카드·파스텔 틴트·알약 배지·그라디언트에서 나온다.

## 2. 대안 4개

### A. 다듬은 스크랩북 (현재 컨셉 정제, 최소 변경)
- 색: 종이 + #C4310D 하나, 상태색은 보도·추정만.
- 타이포: 손글씨는 제목·숫자만, 본문 16px 이상, 위계 3단.
- 레이아웃: 종이 조각 각도 3종 이하, 카드 크기 대·중·소 3종 리듬.
- 모션: hover 120ms 들림만, reduced-motion 존중.
- 글래스: 헤더·탭바 한 곳으로 한정, 투명도 토큰화.
- 장점: 회귀 위험 낮음, 기존 결정 존중, 블러 최소로 성능 양호. 단점: 개성 그대로, 대비 점검 필요. 변경량 약 15%.
```
[글래스 헤더] D-98(손글씨 큰 숫자) | 이번 주 일정(기울인 조각)
── 바인더 탭: 편제표 | 일정 | 제도 ──
학교 요약 3개(대1·중2) / 확인 필요 1줄
```

### B. 가정통신문 (에디토리얼 신문)
- 색: 따뜻한 흰 종이, 먹색 본문, 포인트 1색, 틴트 없음.
- 타이포: 헤드라인만 세리프, 본문 산세리프, 숫자는 tabular.
- 레이아웃: 2~3단, 괘선 구획, 카드·그림자 없음.
- 모션: 거의 없음.
- 배지 대신 문장 "(보도)" 표기.
- 장점: AI 느낌 최소, 성능 최상, 인쇄 친화. 단점: 스크랩북 개성 소실, 모바일 단 접기, 세리프 폰트 용량. 변경량 약 70%.
```
스쿨 라이프            2026.11.01
══════════════════════
[헤드라인] 중학교 졸업까지 D-98
───────┬──────────
이번 주 일정 │ 확인 필요(보도)
```

### C. 조용한 도구 (Things/Linear형)
- 색: 무채색 + 포인트 1색, 내비는 흐리게.
- 타이포: Pretendard 단일, 4단, 큰 숫자 하나.
- 레이아웃: 좌측 내비 + 단일 본문 열, 리스트 중심.
- 모션: 150ms 페이드만.
- 홈은 "오늘 3가지"만, 나머지는 탭 뒤.
- 장점: 가독성·접근성·성능 최고, 유지보수 쉬움. 단점: 스크랩북 결정 번복, 따뜻함 부족. 변경량 약 80%.
```
[흐린 내비] │ 오늘  D-98
편제표      │ ・11/12 …  ・11/15 …
일정·제도   │ 확인 필요 1건
```

### D. 콜라주 보드 (Bento + Are.na)
- 색: 종이 + 포인트 1색, 중요 조각만 짙은 면.
- 타이포: 손글씨 숫자 크게, 라벨은 작은 산세리프.
- 레이아웃: 12열 비대칭, 셀 크기 = 중요도, 같은 크기 인접 금지.
- 모션: 순차 등장 300ms 이하.
- 하위 화면은 A 유지, 홈만 적용.
- 장점: 홈 위계 명확, 개성 강함. 단점: 과밀·모바일 읽기 순서 비용, 유행 피로. 변경량 약 45%.
```
┌──── D-98 (대) ────┬─ 일정 ─┐
├─ 학교 요약 ─┬ 제도 ┼ 링크  │
└────────────┴──────┴──────┘
```

## 3. 권고
기본은 A, 홈에만 D의 크기 리듬을 선택 도입하는 혼합이 효율적이다. B·C는 방향 변경이라 사용자 확인이 필요하다(CLAUDE.md).
