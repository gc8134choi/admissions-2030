## 2. 디자인 컨셉 대안 4개

### A. 현재 컨셉 정제 (최소 변경) — "다듬은 스크랩북"
- 색: 종이 배경 + #C4310D 하나, 상태색(보도/추정)만 별도. 글래스는 헤더·탭바 한 곳으로 한정.
- 타이포: 손글씨는 제목·숫자만, 본문 가독 폰트 16px 이상, 위계는 3단.
- 레이아웃: 종이 조각 각도 3종 이하로 통일, 카드 크기 3종(대·중·소)으로 리듬.
- 모션: hover 살짝 들림 120ms만, prefers-reduced-motion 존중.
- 규칙: 배지는 보도·추정만, 글래스 투명도 고정 토큰화.
- 장점: 유지보수 쉬움·회귀 위험 낮음·기존 결정(C안) 존중. 단점: 개성은 그대로, 글래스와 종이의 이질감은 일부 남음. 가독성 중, 밀도 중, 성능 양호(블러 한 곳), 접근성 대비 점검 필요.
- 변경량: 약 15%(토큰 정리, 글래스 축소, 카드 크기 정리).
```
[글래스 헤더: 스쿨 라이프 | 검색 | 다크]
 D-day 큰 숫자(손글씨)   오늘/이번 주 일정(종이 조각, 약간 기울임)
 ─ 바인더 탭: 편제표 | 일정 | 제도 ─
 학교 요약 3곳(대1·중2) / 확인 필요 1줄
```

### B. 에디토리얼 신문 — "가정통신문"
- 색: 따뜻한 흰 종이(#FAF7F0)·먹색 본문·포인트 1색. 틴트 없음.
- 타이포: 한글 세리프 헤드라인(제목만), 본문 산세리프, 숫자 표는 tabular.
- 레이아웃: 2~3단, 가는 괘선으로 구획, 카드·그림자 없음, 1면 헤드라인 + 단신.
- 모션: 거의 없음, 앵커 스크롤만.
- 규칙: 배지 대신 문장 "(보도)" 표기, 위계는 크기·굵기로.
- 장점: AI 느낌 최소, 성능 최상, 인쇄 친화. 단점: 현재 스크랩북 개성 소실, 모바일 단 접기 설계 필요, 세리프 웹폰트 용량.
- 변경량: 약 70%.
```
 스쿨 라이프            2026.11.01 일
 ══════════════════════════
 [헤드라인] 중학교 졸업까지 D-98
 ───────┬──────────
 이번 주 일정 │ 확인 필요(보도)
 ───────┴──────────
```

### C. 조용한 도구 — "Things/Linear형 캄"
- 색: 무채색 중립 + 포인트 1색, 사이드바는 본문보다 어둡게/흐리게.
- 타이포: 시스템 산세리프(Pretendard), 크기 4단, 큰 숫자 하나.
- 레이아웃: 좌측 내비 + 단일 본문 열, 리스트 중심, 구분선은 최소.
- 모션: 150ms 페이드, 상태 전환만.
- 규칙: 홈은 "오늘 할 일 3개"만, 나머지는 탭 뒤로.
- 장점: 가독성·접근성 최고, 유지보수 쉬움, 성능 최상. 단점: 스크랩북 결정 번복, 가정 포털의 따뜻함 부족, 사용자 재확인 필수.
- 변경량: 약 80%.
```
[내비 흐림] │ 오늘
 편제표       │ D-98 (큰 숫자)
 일정         │ ・11/12 …  ・11/15 …
 제도         │ 확인 필요 1건
```

### D. 비대칭 보드 — "콜라주 보드(Bento+Are.na)"
- 색: 종이 바탕 + 포인트 1색, 중요 조각만 짙은 면, 나머지는 선만.
- 타이포: 손글씨 숫자 크게, 라벨은 작은 대문자성 산세리프.
- 레이아웃: 12열 비대칭 보드, 셀 크기 = 중요도(D-day 대, 나머지 소), 의도적 빈칸.
- 모션: 스크롤 시 순차 등장 최대 300ms, 배치 전환 시 부드러운 이동.
- 규칙: 같은 크기 인접 금지, 셀당 데이터 1종.
- 장점: 개성 강하고 홈 위계 명확. 단점: 밀도 높은 화면 부적합, 모바일 재배치·접근성(읽는 순서) 비용, 유행 피로 위험, 유지보수 중상.
- 변경량: 약 45% (홈 중심, 하위 화면은 A 유지).
```
┌────────D-98────────┬─일정─┐
│ (대, 손글씨 숫자)   ├──────┤
├─학교 요약──┬─제도─┤ 링크 │
└────────────┴──────┴──────┘
```

## 3. 권고
기본은 A로 정리하고, 홈만 D의 크기 차이 리듬을 선택적으로 도입하는 혼합이 변경량 대비 효과가 크다. B·C는 방향 변경이라 사용자 확인이 필요하다(CLAUDE.md의 디자인 방향 규칙).
