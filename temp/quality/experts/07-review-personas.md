# 07 페르소나 인지 워크스루 (계획 초안 기준, 2026-10-29)

방법: 초안의 홈 12열 배치를 따라 보이나(V) / 연결되나(L) / 피드백 있나(F)를 점검했다. 현재 사이트는 열지 않았고 초안 문서만 근거다.

## (1) 페르소나별 결과
| 과업 | ① 중3 학부모(모바일) | ② 초6 학부모(PC) | ③ 중3 학생 |
|---|---|---|---|
| 이번 주 할 일 | 부분 성공. 모바일 순서가 검색 → 일정 → 허브라 V는 되나, "지금 할 일·이번 주"(4열)가 모바일에서 어디로 가는지 없음 | 성공. 2행에 있음 | 부분. 학생 몫과 학부모 몫이 섞임 |
| 중학교 배정 | 해당 없음 | 막힘. 중학교 배정 미니(5행 좌측)가 허브·히어로 아래 3번째 스크롤. 허브 "중입"을 눌러야 L 성립 | 해당 없음 |
| 고교 비교 | 막힘. small multiples가 모바일에서 어떻게 접히는지 미정 | 관심 낮음 | 성공 |
| 선택과목 계획과 대입 요건 | "서울대 권장 충족" 용어를 모름(F 없음) | - | 부분. 4행에서 수치만 보이고 부족 과목이 무엇인지 1클릭 연결은 계획에 있음 |
| 전형 이해 | 막힘. "전형 한눈에" 미니 표가 용어 풀이 없는 표 | 막힘(같은 이유) | 부분 |
| 바뀐 소식 | 5행 우측이라 모바일은 맨 아래. 놓침 | 성공 | 낮은 관심 |

핵심 막힘: 용어(전형·수시·학종·학점·권장 충족)가 풀이 없이 나옴, 모바일에서 5·6행이 사실상 안 보임, "바뀐 소식"에 읽음·새것 표시 피드백 없음.

## (2) 홈 수정안
1. 정보 단위 18~24개는 PC에서는 가능하나 학부모에게는 과밀 위험. 위계를 3단으로 고정한다: A(항상 보임) 검색·다음 일정 히어로·이번 주 할 일, B(요약 숫자 1개씩) 허브·계획표·바뀐 소식, C(접힘) 전형 미니 표·비교·로드맵. 첫 화면에서 A+B 외에는 제목과 숫자 한 개만 둔다.
2. 순서: 검색 → 이번 주 할 일(8열로 키우고 일정 히어로는 4열 요약) → 바뀐 소식을 2행 우측으로 올림(현재 5행). 이유: "바뀐 소식"은 재방문 이유이므로 위에 둔다.
3. 허브 라벨은 상황 말로: "중학교 가는 길"(중입), "고등학교 고르기"(고입), "고교 3년 계획"(고생활), "대입 준비"(대입). 마지막은 내부 약어 금지.
4. 용어 풀이: 첫 등장 용어에 점선 밑줄 + 탭하면 한 줄 풀이 팝오버(ⓘ 과목 설명 방식 재사용). 별도 용어집 메뉴는 만들지 않는다(메뉴 증가를 싫어함). 전형 미니 표는 "학생부종합(서류+면접)"처럼 괄호 한 줄 설명을 기본 노출.
5. "서울대 권장 충족"은 "서울대가 권하는 과목 중 7개 중 5개 이수 예정"처럼 분수와 부족 과목명 1개를 같은 줄에 쓴다.
6. 모바일은 허브를 접힘 아코디언으로 하되 현재 단계만 펼침. 5·6행은 "더 보기" 한 곳으로 모은다.
7. 반투명은 패널 바탕만. 손글씨는 D-day 숫자와 패널 제목까지만, 날짜·학점 숫자는 가독 폰트.

## (3) 현재 단계 결정 제안
자동 추정 + 1회 확인 + 언제나 바꾸기. 첫 방문 때 "지금 자녀는?" 한 질문(중3 / 초6 / 고1 / 고2 / 고3)을 띄워 브라우저에 저장하고, 이후 학년과 날짜(예: 2~3월 입학 직전, 11월 수능 후)로 허브 크기를 자동 조정한다. 홈 허브 띠 끝에 "지금 단계: 중3 · 바꾸기" 링크를 둔다. 두 자녀를 둔 가정은 단계를 둘 선택하게 하고 크게 보이는 허브 2개를 허용한다(단, CLAUDE.md의 "프로필 표시 금지" 결정과 충돌하지 않도록 이름 대신 학년 선택으로만 구현하고, 사용자 확인 필요).

## (4) 놓친 정보 요구
- 오늘 기준 "내가 지금 못 하면 놓치는 것" 마감 한 줄(원서·신청 접수 마감 알림).
- 모든 숫자·일정에 출처와 상태(보도/추정) 병기가 홈 압축 시 사라지지 않게 하는 규칙.
- 중학교 배정 불확실성(근거리 5곳 미확정)을 홈에서 숨기지 말고 "미정" 표시.
- 비용·통학 시간(고교 비교 항목), 학생 몫/학부모 몫 구분, 인쇄·공유(배우자와 공유) 기능, 오프라인 저장.
- 변경 소식의 "새것/읽음" 표시와 바뀐 이유.
