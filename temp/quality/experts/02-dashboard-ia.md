# 02 대시보드·정보 구조(IA) 전문가 의견

## 1. 자료 조사 (한계 먼저)
nngroup.com은 이 세션 네트워크에서 열리지 않았고(WebFetch ENOTFOUND), 검색에도 NN/g 원문이 나오지 않았다. 아래는 2차 요약이라 원문 확인 전에는 인용하지 말 것(허용 도메인에 nngroup.com 추가 필요).
- 허브앤스포크: 스포크는 허브로만 연결되고 작업 뒤 허브로 돌아온다. 최상위 목적지가 7~9개를 넘으면 다른 모델이 필요하고, 대시보드·분석 도구에는 모든 이동을 허브로 강제하는 방식이 마찰이 된다고 한다. https://pattern-playground.onrender.com/patterns/hub-and-spoke , https://cdn.jsdelivr.net/npm/@hegemonart/get-design-done@1.60.4/reference/information-architecture.md
- 메가 메뉴: 내용이 많을 때 효과적이며 NN/g는 패널을 0.5초 지연해 여는 것을 권한다고 전해진다(수치 "클릭 50% 감소"는 미확인). https://bootcamp.uxdesign.cc/the-art-of-mega-menus-a-ux-designers-guide-e63edb812571
- 스캔 패턴: F패턴(2006, 232명 시선추적)은 구조가 나쁠 때 생기는 대체 행동이고, 제목만 훑는 layer-cake가 정보 탐색에 가장 효율적이다. 2019년에 spotted·bypassing·commitment 패턴이 추가됐다. https://www.codecademy.com/article/how-users-scan , https://ssw.com.au/rules/f-shaped-pattern/
- 정부24·학교알리미·대학어디가·Notion·Linear는 조사하지 못했다(미검증). 아래 설계는 일반 원리에 근거한 제안이다.

## 3. 상황 허브 5개 (메뉴 증가 없음, 홈 안의 묶음)
각 허브는 제목 1줄 + 링크 3개 이하 + "지금 상태" 숫자 1개.
1. 중학교 입학: 배정 일정·학교 지도·원서 D-day
2. 중학교 생활: 시기 일정·교과서
3. 고등학교 입학: 과목표 비교·유형·지도
4. 고등학교 생활 + 선택과목: 학점제·내 계획표·로드맵(대입 요건 충족 수치 노출)
5. 대입: 수능·내신 규칙·전형·대학 요건
(현행 구성 유지 + 4번에 대입 연결 한 줄 추가가 최소 변경.)

## 4. 홈 12열 배치 2안 (패널은 크기·각도 차등, 균일 격자 금지)
**A안: 허브 우선(사이트맵형)**
| 행 | 1~4열 | 5~8열 | 9~12열 |
|---|---|---|---|
| 1 | 검색(전폭 12열, 단축키 /) | | |
| 2 | 허브1·2 (중학교) | 허브3·4 (고교) | 허브5 (대입) |
| 3 | 다음 일정 히어로(8열) | | 지금 할 일·D-day(4열) |
| 4 | 계획표 요약(5열) | 고교 비교 표(7열) | |
| 5 | 바뀐 소식(4열) | 3년 로드맵(8열) | |

**B안: 오늘 우선(상태형)**
| 행 | 1~7열 | 8~12열 |
|---|---|---|
| 1 | 다음 일정 히어로 + 검색 한 줄 | D-day·할 일 |
| 2 | 계획표 요약(대입 요건 충족) | 고교 비교 표 |
| 3 | 허브 5개를 한 줄 띠로 압축(전폭, 제목+링크 2개) | |
| 4 | 바뀐 소식 | 3년 로드맵 |

권고: 사이트맵 역할이 요구사항이므로 A안, 단 3행~5행은 B안처럼 상태 패널을 먼저 두는 혼합.

## 5. 모바일 전환 규칙
- 1열, 순서는 검색 → 다음 일정 → 허브(접힘, 제목+숫자만, 탭하면 링크 펼침) → 계획표 요약 → 나머지.
- 중복되는 가운데 탭 바 제거, 하단 탭만 유지. 비교 표는 가로 스크롤 대신 학교별 한 줄 요약.
- 목표: 모바일 홈 높이를 5481px에서 약 3000px 이하로.

## 6. 검색 위치
헤더 돋보기와 홈 입력란을 하나로 합쳐 홈 최상단 전폭 1개로 두고, 다른 화면에서는 헤더 돋보기로 같은 창을 연다. 결과는 학교·과목·일정·용어로 묶어 제목만 훑게 한다(layer-cake).
