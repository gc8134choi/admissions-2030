# 과목 이름 매핑 리포트 (subject-mapping)

생성: `node tools/build-subjects.mjs` (손으로 고치지 않는다). 편제표 DB 과목 136개 ↔ 교육청 안내(subject-info) 231개.
규칙: 공백·가운뎃점 표기를 정규화한 뒤 **완전 일치**만 자동으로 잇는다. 모호·불일치는 안내 내용을 흡수하지 않고(`infoMatch`로 표시) 여기에 남긴다. 임의 매핑은 하지 않는다.

## 요약
자동 일치 126 / 모호 2 / 불일치 8 (합계 136, 묶음 과목 5개는 구성 과목 기준으로 분류)

## 자동 일치 (126)
126 과목은 목록을 생략한다(`subject-master.json`의 `infoMatch: "auto"`).
묶음 과목 중 자동: 미술 창작↔음악 감상과 비평, 미술 창작↔음악 연주와 창작, 미술↔음악, 기술·가정↔정보, 기술·가정↔한문

## 모호 (2) — 후보만 제시, 판단은 사람이
- `관광일본어` 관광 일본어 (제2외국어/한문/교양, 2개교) → 후보: 일본어
- `관광중국어` 관광 중국어 (제2외국어/한문/교양, 3개교) → 후보: 중국어

## 불일치 (8) — 안내자료에 같은 과목 없음
- `심화수학` 심화 수학 (수학, 1개교)
- `문화로보는한국사` 문화로 보는 한국사 (사회, 1개교)
- `한국사심화탐구` 한국사 심화 탐구 (사회, 1개교)
- `정보처리와관리` 정보 처리와 관리 (기술·가정/정보, 1개교)
- `프로그래밍` 프로그래밍 (기술·가정/정보, 1개교)
- `피지컬AI와사고방법론프로젝트` 피지컬AI와 사고방법론 프로젝트 (기술·가정/정보, 1개교)
- `생활과한문` 생활과 한문 (제2외국어/한문/교양, 1개교)
- `주제탐구프로젝트Ⅰ` 주제탐구 프로젝트Ⅰ (제2외국어/한문/교양, 1개교)
