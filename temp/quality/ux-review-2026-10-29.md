# UX 재검토 (2026-10-29)

방법: 처음 쓰는 학부모·학생이 되어 시나리오를 따라가 보고(Playwright로 클릭 수·위치·터치 크기를 쟀다), 390px(한 손)과 1280~1920px(PC)에서 봤다. 메뉴: 오늘 / 중학교 / 고등학교 / 대입 / 일정 + 헤더 보관함.

## 우선순위 1 (고침)
1. **홈 단계 줄(중입·고입·대입)이 화면 두 번째 접힘 아래(y=1169px)에 있었다.** 사용자가 꼭 필요하다고 한 구분이 안 보였다 → 히어로 위로 올리고, 누르면 일정이 아니라 그 단계 첫 화면(중학교 배정 / 학교별 과목표 / 수능·내신 규칙)으로 가게 했다.
2. **고등학교 탭 첫 화면이 학교별 과목표가 아니라 글뿐인 유형·전형이었다** → 학교별 과목표를 앞으로.
3. **어느 단계 화면인지 제목만으로 모른다** → 제목 옆에 손글씨로 "고등학교 입학", "중학교 생활" 등 단계 표시. 홈 3단계 줄에는 현재 가장 가까운 일의 단계를 강조(전에 적용).
4. **칩이 32px이라 한 손으로 누르기 작다**(과목표 28개, 계획표 23개 요소) → 모바일에서 40~44px.

## 우선순위 2 (남김, 제안)
1. 모바일에서 두 번째 줄 메뉴(입학|생활, 항목)가 화면 위쪽에 있어 엄지가 닿지 않는다. 후보: 위쪽 대신 화면 맨 아래 탭 바로 위에 한 줄 고정, 또는 아래로 당기면 나오는 선택 줄. 새 메뉴 항목 없이 가능하지만 설계를 바꾸는 일이라 사용자 의견을 받고 싶다.
2. 일정 화면은 제목 아래에서 표까지 안내문·대상 칩·단계 칩이 세 줄이다. 칩을 한 줄로 합치거나 접어 두기.
3. 학점제 이해 화면(서브 소유)의 목차 링크 131개가 24px 높이 — 서브에 전달 필요(CSS는 임시로 40px 적용).
4. 고등학교 > 생활의 "학년별 로드맵"은 일정 탭으로 이동한다(탭이 바뀌어 길을 잃을 수 있음). 로드맵을 생활 안으로 들이기.

## 우선순위 3 (참고)
1. 중학교 생활은 아직 링크 두 개와 "곧 열려요"뿐이다(데이터 필요).
2. "입학 / 생활" 용어가 부모에게는 낯설 수 있다("고르기 / 지내기" 등 대안은 사용자 의견 필요).
3. 검색은 "설명회"처럼 일정 제목에 있는 말만 걸린다. 설명회 노트 화면이 생기면 색인에 넣기.
4. 단계 칩 선택 값이 바로가기와 일정에서 따로 저장된다(화면마다 기억). 하나로 합칠지 결정 필요.

## 중학교/고등학교 구분이 한눈에 보이는가
- 메뉴: 하단 탭 중학교 / 고등학교가 따로 있다. 안에서도 입학·생활 바인더 탭.
- 제목 옆: 이번에 단계 표시 추가.
- 홈: 3단계 줄을 위로. 일정·소식 행 태그(중입·고입·대입)는 전에 적용.
- 필터 기본값: 일정·바로가기는 "전체"(기본). 사용자가 한 번 고른 단계는 이 브라우저에 기억.
