# 글꼴

- Gaegu Bold, Gowun Batang Bold: SIL Open Font License 1.1, 원본은 Google Fonts(https://fonts.google.com/specimen/Gaegu, https://fonts.google.com/specimen/Gowun+Batang).
- 이 폴더의 woff2는 화면·데이터에 나오는 글자만 남긴 부분 집합이다. 다시 만들려면 `python3 tools/build-fonts.py <Gaegu.ttf> <GowunBatang.ttf>`.
- 본문은 Pretendard(CDN)를 쓴다.
