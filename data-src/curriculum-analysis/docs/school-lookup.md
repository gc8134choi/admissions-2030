## 배정 방식 (4개교 공통 · 2027학년도)
- 용인은 경기도 평준화 지역이며 **구역설정학군**(1단계 학군내배정 → 2단계 구역내배정), "선복수지원-후추첨" 방식. 학생은 거주 학군 내 일반고 5곳을 순위로 적고 추첨 (보도 기준) — reported.
- 용인시는 2015학년도 신입생부터 평준화 편입 (나무위키 수지고 항목) — reported.
- 수지고는 과학중점학교 (나무위키) — reported.
- 결론: 4개교 모두 `assignment: "평준화 추첨(구역설정학군)"`, `region: "경기 용인시 수지구"`. 단, 어느 학군/구역에 속하는지는 학교별 확인 못함.

## 미확인 항목 (교육청·학교알리미로 확인 필요)
- 용인홍천고 개교연도 (설립구분은 사용자가 공립으로 확인). 학교명 표기는 사용자가 "홍천"(홍)으로 확인(기존 "흥천"은 오타). 학교 id(`school-yonginheungcheon`)는 오타 표기에서 유래했지만 유지.
- 학교별 학군·구역 소속, 학교알리미 학교코드(`schoolinfoCode`).
- 학교알리미 직접 조회는 일부 페이지만 판독됐고(수지고), 나머지는 위키·정보 사이트 의존.
