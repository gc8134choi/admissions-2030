# 사용자 언어로 바꿀 용어 후보 (개발 세션 정리, 2026-10-25)

형식: 현재 표기 → 제안 (이유). 적용은 디자인 브리프 확정 후.

## 메뉴
- 제도 변경 로그 → 바뀐 소식 / 제도 변경 알림 (로그는 개발 용어)
- 자료실 > 출처 목록 → 출처 모아보기 (출처는 근거 확인용이라는 점을 드러냄)
- 자료실 > 갱신 현황 → 정보 믿어도 되나요? / 확인 현황 (데이터 신뢰도를 묻는 말투)
- 자료실 > 원본 파일 → 학교에서 받은 자료
- 과목 선택 플래너 > 내 계획표 / 학교별 시뮬레이션 / 목표 학과 요건 충족 리포트 → 내 시간표 짜기 / 이 학교 가면? / 목표 학과 체크
- 고교 선택 > 고교 유형·전형 일정 → 어느 고등학교 갈까 (유형 비교·일정)
- 고교 생활 > 학년별 체크리스트 → 학년별 할 일
- 대입 > 대학·학과 비교 → 대학·학과 찾기
- "준비 중" 메뉴(고교 생활·대입·과목 선택 플래너의 하위 다수) → 열린 뒤에만 노출하거나 "곧 열려요"로 묶기. 메뉴 단순화 선호와 충돌.

## 화면 용어
- 편제표 → 과목 시간표 (학교 편제표는 학교 배부 자료 이름으로 병기)
- 지정 / 선택 → 필수 / 내가 고르는 (지정=학교가 정함, 선택=학생이 고름이라는 뜻을 풀어서)
- 택n 묶음 / 선택 폭 → "n개 중 1개 고르기" 묶음 / 고를 수 있는 폭
- 후보 과목 → 개설 예정 과목
- 창체 → 창의적 체험활동(창체)  (처음에는 풀어서)
- 학교 밖 (이수 방식) → 학교 밖에서 듣는 과목
- 공통 / 일반 / 진로 / 융합 → 공통과목 / 일반선택 / 진로선택 / 융합선택 (줄임말 표시 시 설명 툴팁)
- 수능 범위(추정) / 출제 범위 / 기초(공통) / 제외 → 수능에 나올 것 같아요 / 기초만 / 안 나올 것 같아요 (추정 표시 유지)
- 사진 대조 전 / 원문 미확인 → 아직 원문 확인 전 (한 가지 표현으로 통일)
- 확인 필요 n건 / flag → 직접 확인해 볼 항목
- 보도 / 추정 / 확정 → 기사 기준 / 예상 / 공식 확정 (상태 배지는 유지하되 말은 풀어서)
- 평준화 / 구역설정학군 / 선복수지원-후추첨 → 추첨으로 배정되는 지역 / 우리 지역 학교 묶음 / 지망 쓰고 추첨
- 현고3 / 일반고·과학·영재·자사·외·국제 (일정 대상 칩) → 지금 고3 / 일반고 / 과학고·영재학교 / 자사고·외고·국제고
- D-day 카드의 "시행일(잠정 예상)" → 수능 날짜(예상)
