# 사용자 확인 대기 목록 (2026-11-01 야간 운영 기준)

사용자가 자는 동안 best effort로 진행하고, 아래는 확인이 필요해 남겨 둔 것이다. 사용자는 내일 오전 이후 확인 예정.

## 필요한 입력
1. [보류: 사용자 2026-11-02 "나중에 다시"] 성복초(및 다른 수지구 초등학교) 근거리 중학교 5곳 명단: 용인교육지원청 "중학교 신입생 배정 안내" 첨부 ② 근거리표 화면 캡처. (자동 내려받기가 접근 점검에 막힘, 우회하지 않음)
2. Actions "PR 생성 허용" 설정 켜기(감시 봇이 PR을 열 수 있게). 켜기 전에는 이슈로만 알림.
3. 열려 있는 감시 이슈(#82, #198, #199, #231 등)는 닫기 권한이 막혀 있어 사용자가 직접 닫거나 허용 필요.

## 선택 입력 (사용자가 시간 날 때)
- 중학교 13교 급식·학생수 등: 학교알리미 학교 페이지 URL 몇 개를 복사해 주면(주소의 GS_CD 값) 조사 세션이 일괄 추출. 이름 검색은 브라우저 세션 필요로 자동화 불가(우회 안 함).

## 선택 입력 2 (2026-11-02 전수 감사 결과)
- 사용자가 준 사진·가정통신문을 분석 세션이 판독한 요약 11행(opn-01~05, acd-01~04, life-01·02)은 **원본 이미지가 저장소에 없어** 재대조가 불가능합니다. 원본(학원 설명회 자료, 학교 가정통신문)을 다시 보내 주시면 portal/files에 보관하고 2차 판독해 '확인됨'으로 올립니다. 보내지 않으면 '참고(원본 미보관 요약)' 상태로 화면에 표시합니다.
- 감시 이슈 #82·#198·#199는 반영할 데이터 수정이 없어 닫아도 됩니다(research/watch-issues-status.md). 닫기 허용 여부.

## 디자인 확인 제안 (A3 5회 연속 6.0)
- 칩을 고르지 않은 기본 홈은 '수능 D-day가 맨 위 + 고입→중입→대입 단계순'이라 초6 사용자는 칩을 한 번 눌러야 합니다. 제안: 기본 홈 히어로를 '가장 가까운 마감 1건(단계 무관)'으로 하고 아래에 단계별 1건씩. 홈 디자인 방향이라 사용자 확인 후 구현합니다(PM 추천: 적용).

## 사용자 결정 기록 (2026-11-02)
- 주변 고교 4개 추가 = 풍덕고·성복고·수지고·신봉고(맞음). 선택과목 인원은 공개 자료가 없으면 빈 상태 유지(사유+다음 행동 표기).
- 선택과목 추가 자료(설명회 슬라이드 등) 없음: 홍천고 1곳 외 사진 제공 계획 없음. 조사는 공개 자료만 계속.

## 방향 확인(자율 범위 밖)
- 디자인 방향·메뉴 구조를 바꾸는 제안이 생기면 시안을 temp/에 남기고 여기 추가한다.
- 디자인 컨셉 방향(조사 결과: temp/design/research-2026-11/00-summary.md): ① 현재 컨셉 정제(PM 추천) ② 가정통신문 ③ 조용한 도구 ④ 콜라주 보드. 선택 후 시안 제작.
- 새 기능 후보 중 '개인 체크리스트·관심 학교 저장'은 화면 구조에 영향이 있어 확인 필요.

## 함께 보기(work-through)
- 사용자가 "나중에"로 미룸. 2차 독립 평가 결과와 함께 첫 회를 진행 예정(WORKFLOW.md).

## 사이트 아키텍처 조사 후 확인 필요한 구조 제안 (temp/design/research-2026-11/05-site-architecture.md)
- 학교 상세 전용 주소 `#school/<id>`(개요·편제표·전형·일정·출처 고정 순서): 학교별로 한 화면에서 모아 보는 구조. 메뉴 항목은 늘지 않음.
- '내 목록'(관심 학교·대학·일정 통합 저장, 오늘 화면에 집계): 새 기능, 이름·프로필 없이 기기에만 저장.
- 허브-스포크 개편(각 탭 첫 화면을 허브로): 메뉴 구조 변경.
- 일정 탭 단일화(로드맵·입시 일정을 일정 필터로 흡수): 메뉴 구조 변경.
- 개인 체크리스트(대상 단위 한 줄 추적표).
자율로 진행 중: 주소로 공유 가능한 상태 점검, 빵부스러기, 관련 항목 연결, 기준일·상태·출처·오류 제보 자리 통일.
