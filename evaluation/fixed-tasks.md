# A1 고정 과업 묶음 (2026-11-09 사용자 결정: 6건 고정 + 6건 새로)

A1 과업 12건 중 6건은 매 회 이 묶음을 그대로 쓰고, 나머지 6건(쉬움 3·어려움 3)만 평가자가 새로 구성한다. 회차 간 비교는 고정 묶음으로, 새 표현 일반화는 새 6건으로 본다. 두 결과를 따로 적고, 점수(A1 단계)는 12건 24시도 합산으로 낸다.

## 규칙
- 질문 문구(키워드·문장)는 아래 그대로 쓴다. 바꾸지 않는다. 검색 질의 약 200개와 달리 이 묶음은 과거 질의·searchgold와 겹쳐도 된다.
- **정답 값은 평가자가 그 회차의 데이터에서 다시 확인한다.** 데이터가 바뀌어 정답이 달라졌으면 그 사실을 적고 새 값으로 채점한다(PM 승인 없이 과업을 빼거나 바꾸지 않는다).
- 판정은 evaluator-guide.md의 A·C 절차와 같다(390px 터치, 하단 바 '검색' → 입력 → 상위 3행을 차례로 탭해 도착한 강조 행·열린 용어 창에 정답 값이 있는지).
- 고정 묶음을 바꾸려면 사용자 확인이 필요하다(PM이 이 문서를 고치고 scorecard에 사유를 적는다).

## 기록 방식
- 평가 run 문서 A1 절에 고정 6건×2 = 12시도 결과와 새 6건×2 = 12시도 결과를 표로 나눠 적는다.
- scorecard에는 '고정 묶음 n/12, 새 구성 n/12'를 함께 적어 회차 간 추이를 본다.
- 이 묶음 결과가 나쁜 과업은 검색 패치 대상이 아니라 화면·데이터의 구조 결함으로 본다(검색은 오류만 고친다는 2026-11-07 결정).
