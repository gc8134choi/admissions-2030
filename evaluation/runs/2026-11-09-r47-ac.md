- 배포 기준(최근 3회 평균, 45·46·47차 A+C): A1 (9.0+9.0+9.0)/3 = 9.0/12 = **75.0%**(통과), A2 (7.5+7.5+7.5)/3 = 7.5/10 = **75.0%**(통과), A3 100%, C1 100%, C2 75%. **A·C 항목별 평균은 모두 75% 이상.** 사실 오류 0건 조건: 이번 A·C 범위에서 **신뢰 결함 후보 확정급 1건**(`공동학군` 등 '같은 낱말이 든 자료를 목록에서 찾지 못했어요'가 거짓) + 값 가림 후보(판교중학군 안내 등), 나머지는 소프트(B 평가자·PM 판단).
- 같은 항목이 오르지 않은 이유(필수 보고): **A1 9.0 -> 9.0 유지** - 고정 12/12에 새 구성 9/12로 21/24 = 87.5%, 95%에 3건 부족(N-E1 문장형 1시도 + N-H2 2시도). **A2 7.5 -> 7.5 유지** - 합산 적중률 새 판정 86.3% -> 81.8%, 기존 방식 80.1% -> 75.1%로 75%대 단계 안(90% 미달)이며 자료 있음 83.2%(-2.6%p). **C2 3.75 유지** - 소음 10건·문구 거짓 후보가 있다. **C1 10.0 유지** - 100% 단계(90%+) 안.
