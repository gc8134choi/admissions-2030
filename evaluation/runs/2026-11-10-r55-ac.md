## 9. 측정 한계
(1) 과업·화면 측정은 1회, 로컬 서버(sha 7ec07e8, `python3 -m http.server` 8055), 헤드리스 Chromium 390px 터치, 도착 후 3.6초 대기. A1이 `check-*` 도구와 같은 컨테이너에서 동시에 돌았으나 결과는 도착 후 대기 뒤 읽었다. 라이브 주요 파일 md5 대조는 생략(로컬 sha 기준). (2) 검색 판정은 기대 행 제목 조각 자동 판정 후 수작업 정정(자료 있음 4건 0 -> 1, 반점 3건, 자료 없음 1건 1 -> 0, JSON `manual`) — 정정이 관대하다는 지적이 가능하므로 정정 전 자동 판정 합산(80.8%)도 적는다. 정정 후 A2 단계는 같다(75%대).
