- 배포 기준(최근 3회 평균, 46·47·48차 A+C): A1 (9.0+9.0+9.0)/3 = 9.0/12 = **75.0%**(통과), A2 (7.5+7.5+7.5)/3 = 7.5/10 = **75.0%**(통과), A3 100%, C1 100%, C2 75%. **A·C 항목별 평균은 모두 75% 이상.** 사실 오류 0건 조건: 이번 A·C 범위에서 **신뢰 결함 후보 확정급 2건**(날짜 변형 질의의 거짓 '찾지 못했어요' 문구, 홈 묶음 행 2곳의 날짜·일정 이름 불일치) + 값 가림 후보(아래), 나머지는 소프트(B 평가자·PM 판단). 3회 모두 사실 오류 0건이라는 조건은 이번 회차에서 충족되지 않는다.
- 같은 항목이 오르지 않은 이유(필수 보고): **A1 9.0 -> 9.0 유지** - 24시도 성공률은 95.8%로 95%를 넘었으나 평균 클릭 2.74(학교 속성 질의는 학교 행이 항상 1위, 값 행이 2위; F6 3위)라 클릭 <=2를 못 채움. **A2 7.5 -> 7.5 유지** - 합산 적중률 새 83.6%(+1.8%p)·기존 75.9%(+0.8%p)로 같은 75%대 단계, 90% 미달. **C2 3.75 유지** - 정직 안내율은 올랐으나 문구가 사실과 다른 질의(날짜 변형)·무관 행 소음이 남음. **C1 10.0 유지** - 100% 단계(90%+) 안.
